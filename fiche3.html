Boxhotel

TYPE DE PROJET

Intégration HTML/CSS/JS

CONTEXTE

Projet scolaire

Recréer un site web d'hôtellerie à l'identique d'une maquette Figma, page par page, en HTML, CSS et JavaScript — jusqu'au moindre détail.

VOIR LE SITE WEB

Contexte

Projet scolaire visant à recréer intégralement un site web à partir d'une maquette Figma fournie, sans aucune liberté créative sur le design. L'exercice portait entièrement sur la précision de l'intégration : chaque page devait reproduire fidèlement la maquette, au pixel près, en HTML, CSS et JavaScript.

Crédits

Intégration complète (HTML/CSS/JS) réalisée en solo. Maquette Figma conçue par Tatiana Titov, fournie dans le cadre du cours. Toutes les pages sont fonctionnelles et fidèles au design original.

Processus

PLAN 01

Analyse de la maquette

Étude complète de la maquette Figma fournie par Tatiana Titov — structure des pages, espacements, typographie, composants répétés — pour repérer les éléments réutilisables avant de commencer l'intégration.

PLAN 02

Installation des médias

Extraction et organisation de toutes les images et icônes du site directement depuis Figma, classées par page et par section pour éviter les allers-retours constants vers la maquette en cours d'intégration.

PLAN 03

Intégration du HTML

Construction de la structure HTML complète de chaque page, en respectant la hiérarchie exacte de la maquette (sections, composants, répétitions) pour que le balisage reflète fidèlement l'organisation visuelle prévue.

PLAN 04

Intégration du CSS

Écriture du CSS complet, divisé par section plutôt que dans un seul fichier, pour garder le code organisé et plus facile à ajuster page par page durant le développement.

PLAN 05

Intégration du JavaScript

Création d'une component factory et de composantes réutilisables pour gérer le fonctionnement dynamique du site, incluant la page modale, plutôt que de dupliquer la logique à chaque occurrence.

VOIR LE SITE EN LIGNE

Défis

Reproduire fidèlement la maquette Figma au pixel près, tout en structurant le JavaScript pour que la page modale et les composants répétés fonctionnent sans dupliquer le code partout.

Solutions

Création d'une component factory en JavaScript pour générer les composantes réutilisables à partir d'un seul bloc de logique, plutôt que de recoder chaque instance manuellement.

Apprentissage

Une meilleure compréhension de la structuration du JavaScript en composantes réutilisables, et de l'importance de séparer le CSS par section pour garder un code organisé sur un projet à plusieurs pages.
